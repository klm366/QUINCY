The consuming processes (`mo_assimi_interface`, `mo_carbon_interface`, `mo_pheno_interface`, `mo_rad_interface`) are unchanged:
- They replace CarboxRate and ETransport only where both Vcmax25 and Jmax25 are dynamic.
- They replace specificLeafArea_C where SLA is dynamic.
- A trait of 0 (the first year, or missing predictors) keeps the lctlib value.

Every PFT tile has its own seven trait variables. Their output names put the tile first: `trait_<tile>_<variable>`, e.g. `trait_pft04_sla_pred`, `trait_pft13_vcmax25_pred`; `trait_veg_*` and `trait_box_*` are the fraction-weighted means of the child tiles. The variables are `vcmax25_raw`, `vcmax25_pred`, `jmax25_raw`, `jmax25_pred` (C4: PEPcase CO2 specificity, mmol m-2 s-1), `sla_raw`, `sla_pred` (m2 kg-1 leaf carbon) and `jmax_vcmax_ratio`; 0 means that the PFT has no climate relationship and keeps its lctlib value.

## Decisions and evidence

All decisions and their evidence are written in the README headers of the generator scripts:
- `Manuscript1/scripts/trait_variability_12PFT/make_trait_fortran_table_20261001.py` (E1–E8);
- `Manuscript1/scripts/trait_variability_12PFT/make_lctlib_S1_S2_20261001.py` (R1–R5).

The key decisions are:
- Every Table 3 relationship that passes the filters is used (19 of 20).
- Pooled relationships use per-PFT bounds.
- C4 Jmax25 is never applied, because ETransport of a C4 tile is the PEPcase CO2 specificity.
- C4 S2 changes only SLA.
- Pastures copy the grasses.
- PFT13 Vcmax25 and Jmax25 stay static: their MAT and MAP terms are not significant (p = 0.18–0.78).
- `lctlib_nlct22_mangrove_control.def` is not used, because its Fract_npp_2_woodPool is 0.3 instead of cmip7's 0.4.

## Offline test

`Manuscript1/scripts/trait_variability_12PFT/fortran_test/test_trait_fortran_20261001.py` compiles `mo_climbuf_process.f90` and `mo_trait_process.f90` with gfortran (`-std=f2008`):
- TRAIT matches Table 3, evaluated independently, to 1.3e-12 over 4,400 random climates.
- The CLIMBUF annual means match to 4e-14.
- The interface and memory modules need the full ICON build (step 7, Levante).

## Known points

- `lctlib_nlct22_mangrove_zhao_static.def` holds specificLeafArea_C 0.166656 m2 molC-1 = 13.875 m2 kgC-1. EXPERIMENTS_README quotes 0.014752 m2 gC-1 (14.75 m2 kgC-1). The model file is kept.
- The PFT13 SLA equation is kept from the validated implementation (MAP, Tmax, MAP·Tmax). It has to be refitted with the Table 3 method before E4–E6.
- Restarts written before this branch lack the new variables. TRAIT then returns 0 until the first complete year (`reh_prev_year > 0` check), so the lctlib values are used.
