Purpose
-------
Prepare diagnostic and visualization workflows for
future mangrove trait-climate regressions.

Scientific Logic
----------------
Trait-climate regressions require:
- outlier inspection
- coordinate validation
- species balance inspection
- climate-space inspection
- regression diagnostics

Planned Diagnostics
-------------------
Trait distributions:
- SLA histograms
- Vcmax25 histograms
- Jmax25 histograms

Climate distributions:
- BIO01 temperature histograms
- BIO12 precipitation histograms

Regression diagnostics:
- residual plots
- R²
- RMSE
- leverage diagnostics
- species-specific comparisons
