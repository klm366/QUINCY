\section{Land Model Driver}
\label{sec:land_model_driver}

\textbf{Basic structure and functionality:}
\begin{itemize}
\item 0.2 Local variables
\begin{itemize}
\item l{\_}forcing
\item iblk, ics, ice, nc
\item REAL(wp), ALLOCATABLE, DIMENSION(:)  :: a2l and l2a memory
\end{itemize}
\item 1.0 Create tile and run model init: init{\_}model (mo{\_}jsb{\_}model{\_}init)
\item 2.0 allocate forcing variables (DIMENSION(nc)), open forcing input file IF \texttt{l\_forcing} == TRUE, and init output files
\item 3.0 time loop
\begin{itemize}
\item call update forcing (drivers/mo{\_}atmland{\_}forcing)
\item call land model interface (section \ref{sec:land_model_interface})
\item check timer and adjust year counter (periodically increase time{\_}year by 1)
\item write special fluxnet output (flag: base{\_}config\%fluxnet{\_}output)
\end{itemize}
\item 4.0 close output and forcing files
\end{itemize}

\section{Land Model Interface}
\label{sec:land_model_interface}

The interface (interfaces/mo{\_}land{\_}model{\_}interface.f90) runs SLM (land, plant, canopy, soil, test{\_}canopy) for one time step.
~\\


\textbf{Basic structure and functionality:}
\begin{itemize}
\item \texttt{CALL update\_a2l} (atm2land forcing)
\item select the SLM model (base{\_}config\%slm{\_}model{\_}name) and run the tasks according to the Call-Tree
\begin{itemize}
\item land
\item plant
\item soil
\item canopy
\item test{\_}canopy: \texttt{CALL run\_test\_canopy\_model  (tile, model)} (this routine is defined within mo{\_}land{\_}model{\_}interface)
\end{itemize}
\item \texttt{CALL update\_l2a} (return updates values from land2atm)
\end{itemize}
~\\

\textbf{SLM plant: Call-Tree a.k.a. Queue}
\begin{enumerate}
\item set{\_}zero{\_}vegetation{\_}fluxes
\item update{\_}radiation
\item update{\_}vegsoil{\_}bgc
\item update{\_}phenology
\item update{\_}canopy{\_}fluxes
\item update{\_}growth
\item update{\_}veg{\_}turnover
\item update{\_}veg{\_}dynamics
\item update{\_}sb{\_}pools
\item update{\_}soil{\_}physics
\item update{\_}veg{\_}pools
\item update{\_}time{\_}averages
\item write data: write{\_}output{\_}pool and write{\_}output{\_}flux
\end{enumerate}

\textbf{SLM soil: Call-Tree a.k.a. Queue}
\begin{enumerate}
\item update{\_}sb{\_}pools
\item write data: write{\_}output{\_}pool and write{\_}output{\_}flux
\end{enumerate}

\section{Model Init}
\label{sec:model_init}

\textbf{Basic structure and functionality:}
\begin{itemize}
\item 1.0 process config: read namelist parameters and run PROC{\_}config\%init routines
\item 2.0 model init: ALLOCATE(jsbach\%models(no{\_}of{\_}models)) and set model options
\item 3.0 tile init, includes set pft{\_}id
\item 4.0 grid init: get lon lat from namelist
\item 5.0 process constants init
\item 6.0 process memory init and allocation (\texttt{tile\%mem(PROCESS)\%p})
\item 7.0 lctlib init
\item 8.0 time init (e.g. \texttt{dt = base\_config\%dt})
\item 9.0 IF base{\_}config\%fluxnet{\_}output THEN init fluxnet specific simulation output (half-hourly write-out of values for the last full forcing period)
\item 10.0 enable/ disable forcing and run SLM model specific init routine (\texttt{init\_slm\_MODEL(model,tile)})
\begin{itemize}
\item land and plant
\item soil
\item canopy
\item test{\_}canopy (nothing to do here)
\end{itemize}
\end{itemize}
